How I ran it with no local GPU

1. Download Nemotron-3-Diarization-preview.nemo from the NGC diarization-ea team (Early Access).
2. Open notebooks/nemotron_3_diarization_colab.ipynb in Google Colab, pick a T4 GPU, upload the .nemo to Drive.
3. The notebook loads NeMo, diarizes, optionally transcribes, and launches Gradio so the same speaker-lane UI runs next to the GPU.
4. This Mac only hosts the showcase — Demo mode, no CUDA.
