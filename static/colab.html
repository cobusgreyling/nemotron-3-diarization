The GitHub “Open in Colab” link cannot see a private repo.

Colab fetches notebooks from GitHub as a guest, so colab.research.google.com/github/… 404s while this repository is private. Upload the notebook file instead — that always works.

Do this (about 30 seconds)

  1. Download the notebook: nemotron_3_diarization_colab.ipynb
  2. Open a blank Colab: colab.research.google.com
  3. File → Upload notebook → choose the file you just downloaded.
  4. Runtime → Change runtime type → T4 GPU → Save.
  5. Put Nemotron-3-Diarization-preview.nemo on Drive (from Downloads), then Runtime → Run all.
